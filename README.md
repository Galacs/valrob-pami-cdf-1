# Carte Pami CDF 1

Pami integrated circuit board with dual silent stepper driver and ToF sensor

## IC List

- ESP32-S3FH4R2 (Main MCU)
- LDL212 (MCU 3v3 LDO)
- BQ77905 (battery protection)
- WS2812B (RGB addressable led)
- MLT-5020 (buzzer)
- VL53L0X (ToF ranging sensor)
- 2x TMC2209 (Silent 3A stepper driver)
